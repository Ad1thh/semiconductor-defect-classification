Introduction

Semiconductor Fabrication Scale

Modern integrated circuits operate at sub-10 nm nodes on 300 mm silicon wafers, involving over 500 lithography, CMP, etching, and thin-film deposition cycles.

Spatial Wafer Defect Signatures

Equipment malfunctions cause spatially correlated clusters of failed dies across wafer discs (Center, Donut, Scratch, Edge-Ring, Edge-Loc, Loc).

WM-811K Industrial Benchmark

Evaluated on the authoritative WM-811K benchmark containing 811,457 commercial wafer maps collected from actual fab production lines.

Automated Optical Inspection (AOI)

Inline defect classification allows instant diagnosis of malfunctioning fab equipment, preventing wafer lot scrap and saving millions in fabrication costs.

Speaker Note: Semiconductor fabrication requires hundreds of high-precision chemical and mechanical stages. When a tool malfunctions, defective chips form characteristic spatial patterns. Automated Optical Inspection (AOI) is crucial for identifying these patterns immediately to diagnose root causes before entire lots are ruined.

Problem Statement

Inspection Throughput Bottlenecks

Commercial fabs produce >50,000 wafers monthly; conventional manual microscopy inspection is slow, subjective, and highly prone to operator fatigue.

Extreme Industrial Class Imbalance

In actual production lots, over 78% of wafers are nominal (clean), making systematic minority defect classes difficult to detect with standard classifiers.

Edge Compute Constraints

Traditional deep CNNs (VGG-16, ResNet-50) require multi-gigabyte GPU memory and high latency (>50 ms), making inline fab shop-floor deployment infeasible.

Core Problem Definition

Develop an ultra-lightweight, edge-deployable deep learning framework achieving >98% accuracy and sub-2 ms latency across multi-class wafer defects on commodity CPUs.

Speaker Note: Our problem statement addresses three critical industrial challenges: manual inspection cannot handle high volume, 78% class imbalance severely skews models, and traditional heavy models cannot run on shop-floor edge CPUs. We formulate a lightweight solution delivering >98% accuracy at sub-2 ms latency.
04 / 11

Need for the Project

Yield Economics & Cost Savings

Detecting defective wafers early in the fab cycle prevents flawed dies from entering expensive dicing, packaging, wire-bonding, and encapsulation processes.

Direct Tool Root-Cause Traceability

Topological patterns map directly to equipment failures: Center → CMP slurry; Donut → RTA thermal gradient; Scratch → robot handling; Edge-Ring → plasma etch.

Edge Inline Autonomy

Eliminates cloud network transmission latency, bandwidth costs, and proprietary fab IP security risks by running inference directly on local fab equipment controllers.

Zero-Overhead Fab Integration

With an ONNX binary of just 5.84 MB, the system integrates seamlessly into legacy automated test equipment (ATE) and smart industrial cameras.

Speaker Note: Early defect detection saves millions in semiconductor packaging costs. Furthermore, defect patterns provide immediate root-cause traceability to specific fab tools. Edge deployment guarantees zero latency and keeps proprietary fabrication data strictly within the factory cleanroom.

Objectives

01

Large-Scale Dataset Curation & Normalization

Extract, filter, and balance the industrial WM-811K benchmark (811,457 wafer maps) into standardized 224×224 grayscale representations across 8 defect categories.

02

Lightweight Deep Neural Network Design

Implement and fine-tune MobileNetV3-Small with depthwise separable convolutions and Squeeze-and-Excitation (SE) channel attention for spatial defect isolation.

03

Hardware-Agnostic ONNX Optimization

Export trained PyTorch weights to an optimized ONNX runtime graph (Opset 12) achieving sub-2 ms CPU latency and a compact 5.84 MB binary footprint.

04

Interactive AOI Fab Demonstrator & Telemetry

Develop a full-stack automated inspection system featuring an interactive 300 mm wafer canvas, live die pass/fail matrix, fab lot simulator, and REST API.

Speaker Note: Our four concrete objectives were: 1) Curate and balance the WM-811K benchmark; 2) Formulate the lightweight MobileNetV3-Small architecture; 3) Optimize via ONNX runtime for sub-2 ms edge execution; and 4) Deliver an interactive AOI fab demonstrator with die pass/fail telemetry.

WM-811K Dataset & Wafer Defect Patterns

Dataset Profile & Industrial Challenges

  • Total Records: 811,472 real semiconductor wafer maps collected from 46,393 fabrication lots.
  • Labeled Samples: ~172,950 annotated wafers categorized into failure patterns.
  • Severe Imbalance: >96% of manufactured wafers are defect-free (Clean nominal yield).
  • Array Representation: 2D discrete matrices (0 = background, 1 = pass die, 2 = defect die).
  • Automated Preprocessing:
    • Custom pandas Int64Index unpickling patch
    • Bilinear resizing to 224×224 resolution
    • Grayscale pixel scaling (0–255 PNG)
    • 70% Train, 15% Validation, 15% Test stratified split

Methodology & Implementation Workflow

PHASE 1

Dataset Curation & Preprocessing

  • Extracted wafer matrices from WM-811K benchmark.
  • Applied spatial bicubic/nearest resizing to 224×224 pixels.
  • Normalized pixel tensors with ImageNet mean and variance.
  • Formulated 70% Train, 15% Val, 15% Test stratified partitions.
PHASE 2

Transfer Learning & Model Fine-Tuning

  • Utilized pre-trained MobileNetV3-Small deep convolutional backbone.
  • Depthwise separable convolutions + Squeeze-and-Excitation (SE) attention.
  • Configured customized 8-class linear classifier output head.
  • Hard-Swish non-linear activation functions for efficiency.
PHASE 3

Training & Regularization Pipeline

  • Adam optimizer (learning rate = 3e-4) with Cross-Entropy loss.
  • Dropout regularization (p = 0.2) to prevent majority-class overfitting.
  • Early stopping based on validation loss checkpoints.
  • Trained over 8 complete epochs on balanced wafer batches.
PHASE 4

ONNX Compilation & Web Integration

  • Exported PyTorch computation graph to ONNX Opset 12 format.
  • Constant folding and graph pruning yielding 5.84 MB binary.
  • Integrated with high-concurrency Python REST inference server.
  • Developed interactive HTML5 canvas AOI demo with die telemetry.
Speaker Note: Our 4-phase methodology covers the complete implementation lifecycle: Phase 1 handles data extraction; Phase 2 adapts the MobileNetV3-Small architecture; Phase 3 trains with Adam and Cross-Entropy loss; and Phase 4 optimizes into ONNX for web and shop-floor integration.

Experimental Results & Outcomes

Performance Metrics (121,719 Test Samples)

  • Overall Test Set Accuracy: 98.02%
  • Inference Latency: 1.53 ms per wafer on CPU (zero GPU needed)
  • Model Size: 5.84 MB (ultra-compact ONNX binary)
  • Macro Precision: 0.6897 • Macro Recall: 0.6177
  • Per-Category Verification:
    • Clean: 99.98% Precision (100% detection rate)
    • Scratch: 99.92% Confidence score
    • Donut: 99.99% Confidence score
    • Center: 98.01% Confidence score
    • Edge-Loc & Loc: >99.2% Confidence score
